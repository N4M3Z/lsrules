# Publication document provenance

## ADDED Requirements

### Requirement: Exact document digest exceptions

The package check MUST exempt only verified digest character spans in the supported adoption record structure.
The subject MUST match its exact local Markdown bytes and its sidecar record name.
Every replacement digest and digest in its path MUST match the exact referenced replacement bytes.
The upstream digest MUST match a local source file named by that digest under the provenance sources directory.
The check MUST NOT use a global digest allowlist or skip the provenance directory.

#### Scenario: Complete local document evidence

- **WHEN** the record structure and all referenced document bytes pass verification
- **THEN** only the corresponding digest character spans receive an exception from the fingerprint scan

#### Scenario: Missing or changed upstream bytes

- **WHEN** the upstream source is missing or its bytes do not match the declared digest
- **THEN** provenance verification fails and the digest receives no exception

### Requirement: Unsupported input fails closed

The check MUST reject extra fields, duplicate fields, extra documents, aliases, anchors, mismatched paths, and duplicate replacement block references.
It MUST reject symlinks in public package content before it scans file text.
It MUST also reject symlinks in a record path or referenced document path.
It MUST reject paths outside the package and non-UTF-8 document bytes.
The supported structure MUST remain limited to the current adopt/v1 emitter shape.

#### Scenario: Record contains an extra field

- **WHEN** a record adds a field beyond the supported structure
- **THEN** the package check fails without granting any digest exception

#### Scenario: Replacement path uses a symlink

- **WHEN** a replacement path contains a symlink component
- **THEN** the package check refuses the reference even when its target bytes match

#### Scenario: Provenance directory is a symlink

- **WHEN** the provenance directory is a symlink that directory discovery does not traverse
- **THEN** the package check fails instead of silently omitting its contents

#### Scenario: Policy file is a symlink

- **WHEN** a required policy or catalog file is a symlink
- **THEN** the package check fails before it reads any package content

### Requirement: Other content retains privacy checks

All public record text and referenced public document text MUST remain in the other package privacy scans.
Unrecognized text and hidden public package files MUST retain fingerprint checks.
Root version-control metadata and generated bytecode remain outside the publication content scan.
Only the explicitly verified private submodule boundary may exclude private payload from public validation.

#### Scenario: Verified digest appears in unrelated text

- **WHEN** a digest from a verified record also appears in an unrelated note or field
- **THEN** that other occurrence fails the fingerprint scan

#### Scenario: Referenced source contains private data

- **WHEN** a correctly hashed source contains a private path, address, or executable fingerprint
- **THEN** the matching privacy check fails

### Requirement: Integrity claims remain bounded

The result MUST establish byte consistency only.
It MUST NOT claim upstream authenticity, independent review, native firewall enforcement, or publication.

#### Scenario: All package checks pass locally

- **WHEN** local package validation passes
- **THEN** the result remains a local validation outcome without a publication or authenticity claim

### Requirement: Literal address privacy checks

The text scan MUST reject IPv4 and IPv6 address literals without network activity.
IPv6 validation MUST use the Python standard library after lexical candidate extraction.
The scan MUST cover expanded, compressed, mapped, scoped, bracketed, and URL forms.
It MUST NOT exempt private, link-local, loopback, unspecified, or documentation address ranges.
Ordinary colon prose, timestamps, and version strings MUST remain valid.

#### Scenario: Hidden document contains a scoped IPv6 URL

- **WHEN** a hidden package document contains a bracketed IPv6 URL with a zone suffix
- **THEN** the package fails its literal address privacy check

#### Scenario: Document contains ordinary timestamps

- **WHEN** a document contains colon prose, ordinary timestamps, and version strings without address literals
- **THEN** the literal address privacy check passes
