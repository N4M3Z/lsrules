# Evidence and validation

- An Unapproved marker is an annotation. It does not change traffic matching.
- A native export records the model state at one time.
- A local policy file records intended portable policy.
- Runtime traffic proves observed connectivity only.
- Host metadata records machine-specific observations.
- Keep these evidence types separate in reports.
- State the source path, checksum, time, and validation method for each inspected artifact.
- Compare process, parent, destination, protocol, port, action, direction, and profile separately.
- Report unknown or unavailable evidence as a limit.
- Do not infer runtime enforcement from a successful request.
- Use offline validators before any native review.
- Do not claim native acceptance without native evidence.
