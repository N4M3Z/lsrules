# Scope and publication

- Keep the user's explicit scope until the user changes it.
- Do not repeat approval questions for work inside that scope.
- Do not use repeated save, restore, or export cycles as a verification substitute.
- Never restore a complete firewall model when a narrow edit can solve the problem.
- Never disable identity checks or allow all connections as a blanket repair.
- Never remove or weaken ChatGPT access without an explicit user request.
- Keep private backups, host names, addresses, account data, and credentials outside public files.
- Use placeholders for machine-specific paths and identities.
- Ask before the exact commit, repository creation, or push.
- Do not run network probes, provider tests, or external validation automatically.
