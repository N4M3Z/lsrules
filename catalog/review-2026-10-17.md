Phishing Army licenses its generator under GPL-3.0. That software license does not replace upstream intelligence-data terms.
HaGezi keeps legacy Hosts and Subdomains formats in a separate repository.
Select the current native preset and verify its format before subscribing.

The legacy URLhaus hostfile address is a reference, not a verified anonymous download endpoint.
Do not place an Auth-Key in this repository, a committed URL, or a shared rule group.
Native catalog access can differ from direct API access. Verify it separately in the native application.

Source terms and endpoints can change. Recheck them before copying data, building a service, or changing the distribution scope.
This package deliberately includes no source data whose redistribution terms remain unresolved.
